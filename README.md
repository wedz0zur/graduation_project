# Geometrica — Интернет-магазин премиальной керамической плитки

Полнофункциональный интернет-магазин по продаже керамической плитки, керамогранита и отделочных материалов. SPA с отдельным бэкендом и фронтендом, связанными через REST API.

**Адрес магазина (офлайн):** г. Иркутск, ул. Старо-Кузьмихинская, 41/3

---

## Технологический стек

**Бэкенд:** NestJS, TypeORM, SQLite, Passport (JWT), bcryptjs, class-validator  
**Фронтенд:** Next.js, React, Zustand, Tailwind CSS, Playfair Display + Inter  
**База данных:** SQLite (файловая, не требует сервера)

---

## Возможности

- **Каталог товаров** — фильтрация по категории, бренду, цене, скидкам; сортировка по цене и названию
- **Карточка товара** — фото, описание, характеристики, похожие товары, добавление в корзину и избранное
- **Корзина** — управление количеством, контактные данные (предзаполнены из профиля), выбор способа оплаты
- **Оформление заказов** — отправка заказа на бэкенд с привязкой к пользователю; заказы отображаются в профиле
- **Личный кабинет** — просмотр истории заказов, редактирование профиля, смена пароля
- **Избранное** — сохранение понравившихся товаров
- **Админ-панель** — CRUD товаров, inline-редактирование названия и цены
- **Аутентификация** — регистрация, вход, JWT-токены (7 дней), защищённые эндпоинты

## Быстрый запуск

### 1. Бэкенд

```bash
cd backend
npm install
npm run dev
```

Запускается на `http://localhost:3001`. БД и тестовые товары создаются автоматически при первом запуске.

### 2. Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Запускается на `http://localhost:3000`.

### Очередность

Сначала бэкенд (создаст БД), затем фронтенд.

## API endpoints

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | /api/auth/register | Публичный | Регистрация |
| POST | /api/auth/login | Публичный | Вход |
| GET | /api/users/profile | JWT | Профиль пользователя |
| PUT | /api/users/profile | JWT | Обновление профиля |
| GET | /api/products | Публичный | Список товаров (с фильтрами) |
| GET | /api/products/:id | Публичный | Один товар |
| POST | /api/products | JWT (admin) | Создание товара |
| PUT | /api/products/:id | JWT (admin) | Обновление товара |
| DELETE | /api/products/:id | JWT (admin) | Удаление товара |
| GET | /api/orders | JWT | Заказы пользователя |
| POST | /api/orders | Публичный | Создание заказа |

## Особенности реализации

- **Корзина на фронтенде** — данные хранятся в localStorage через Zustand persist
- **JWT без сессий** — токен живёт на клиенте, сервер не хранит сессии
- **Авто-синхронизация БД** — TypeORM `synchronize: true` создаёт таблицы по entity-классам
- **SQLite** — вся БД в одном файле, не требует установки PostgreSQL/MySQL
- **Server/Client разделение** — статические страницы — серверные, интерактивные — клиентские
